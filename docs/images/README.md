# Capturas de tela do README

Salve as imagens desta galeria nesta pasta usando exatamente estes nomes:

| Arquivo | Conteúdo recomendado |
|---|---|
| `accounts.png` | Tela de contas em grade, com uma conta ativa e alguns favoritos |
| `games.png` | Biblioteca de jogos com capas carregadas |

## Recomendações para os prints

- Use PNG.
- Mantenha todas as capturas na mesma resolução, preferencialmente `1440 × 900` ou `1600 × 1000`.
- Redimensione a janela do SteamNexus de forma idêntica antes de cada captura.
- Evite mostrar notificações, nomes de pastas pessoais, SteamID, API keys ou outros dados sensíveis.
- Use contas e nomes que você não se importe em tornar públicos.

## Exibir a galeria

Depois de adicionar as duas imagens, abra o `README.md` na raiz do projeto e remova os marcadores de comentário `<!--` e `-->` que envolvem o bloco da galeria. Em seguida, remova a frase que informa que as capturas serão adicionadas.
